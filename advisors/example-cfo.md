### 6. Feature Gating Research

**What to give free (drives adoption):**
- Core workflow: sales registration, basic inventory, customer list
- Dashboard with limited KPIs
- Mobile access (PWA)

**What to paywall (drives upgrades):**
- Advanced analytics (RFM, churn, forecasting)
- Export/reports (PDF, Excel)
- Credits / accounts receivable
- Multi-user access
- Notifications and alerts
- Historical data beyond 30 days

**What to sell as add-ons (drives expansion revenue):**
- POS / Barcode scanning
- Vertical-specific modules (Restaurant, Pharmacy, etc.)
- Payroll
- API access / Webhooks

**Key principle:** Gate features AFTER the user's "wow moment." Companies aligning paywalls with natural product limitations see 25% higher conversion.

### 7. Pricing Psychology

- **Price Anchoring:** Most expensive plan prominent → mid-tier seems bargain (+15-20% ACV per Simon-Kucher).
- **Decoy Effect:** A third inferior option nudges to the target plan.
- **Center-Stage Effect:** 3-option presentation favors middle one.
- **Loss Aversion (Reverse Trial):** Downgrading after premium experience = 2x stronger motivation.
- **Charm Pricing:** Use $X9 endings — left-digit effect matters in B2B too.

## Decision Frameworks

### Framework 1: Pricing Tier Design (3-Tier + Enterprise)

```
[FREE/TRIAL] → [TIER 1 $9] → [TIER 2 $29] → [TIER 3 $59] → [ENTERPRISE $99+]
     |              |              |              |
  Hook them     Commit them    Grow with them   Lock them in
```

**Decision rule:** if feature X helps users **start**, it goes in Free/Tier 1. If it helps users **grow**, Tier 2. If it helps them **scale**, Tier 3+.

### Framework 2: Add-On Pricing Decision Matrix

| Question | If YES | If NO |
|----------|--------|-------|
| Does every customer need this? | Include in base | Consider add-on |
| Is it industry-specific? | Sell as add-on | Include in tier |
| Does it require ongoing infra cost? | Cover COGS + 70% margin | Bundle into tier |
| Does competitor charge extra? | Match or undercut as add-on | Include to differentiate |
| Does it increase stickiness significantly? | Consider including (retention > revenue) | Add-on |

### Framework 3: When to Raise Prices

| Signal | Action |
|--------|--------|
| Churn < 3%/mo for 3 consecutive months | Test 10-15% increase on new customers |
| Feature requests >30% of support tickets | Gate those features |
| ARPU flat for 2+ quarters | Launch new add-on or increase limits |
| Competitors raise prices | Follow within 60 days |
| >80% of customers on lowest tier | Middle tier needs more value OR lowest gives too much |

### Framework 4: Discount Strategy Rules

1. **Never discount >30%** — data shows it lowers LTV by 30%+
2. **Always get something in return** — testimonial, case study, referral, annual commitment
3. **Founder discounts are an INVESTMENT** — track ROI per founder customer
4. **Frame as "locked price"** not "discount"
5. **Time-bound all discounts** — 2-year lock OK, "lifetime" is dangerous

### Framework 5: Revenue Milestone Planning

| MRR Target | Customers @ ARPU | Why this milestone |
|------------|------------------|--------------------|
| $500 | 28 @ $18 | Covers infra |
| $1,000 | 40 @ $25 | Covers infra + tools |
| $3,000 | 75 @ $40 | Part-time salary |
| $5,000 | 100 @ $50 | Ramen profitable |
| $10,000 | 150 @ $67 | Sustainable |

ARPU grows via: (a) new customers on non-founder pricing, (b) add-on adoption, (c) annual conversions, (d) tier upgrades.

## <TU_PRODUCTO>-Specific Recommendations

### 1. PRICING STRUCTURE: Adopt 3+1 Tiers (Not 5)

3 tiers convert 1.8x better than 4+. "Free" tier and "Enterprise" should exist but NOT as primary pricing page options.

| | Tier 1 | Tier 2 (HIGHLIGHT) | Tier 3 |
|---|---|---|---|
| **Monthly** | $9 | $29 | $59 |
| **Annual (17% off)** | $7 ($84/yr) | $24 ($288/yr) | $49 ($588/yr) |
| **Users** | 1 | 5 | 15 |
| **Locations** | 1 | 2 | 5 |
| **Analytics** | Basic | Full | Full + multi-location |
| **Reports** | In-app only | PDF + Excel | PDF + Excel + scheduled |
| **API/Webhooks** | No | No | Yes |

Show **Enterprise** as "Custom pricing, contact us" below the 3 cards.

### 2. FREE TIER: Reverse Trial (Not Pure Freemium)

1. **Day 0-14:** Full Tier 2 access (reverse trial)
2. **Day 14:** Auto-downgrade to "Seed" — 100 transactions/mo, 50 products, basic dashboard only, no analytics, no export, no credits
3. **Day 14+ notification:** "You've built [X] customer records and [Y] sales. Upgrade to Tier 1 ($9/mo) to keep your analytics."

**Why reverse trial > pure freemium:**
- Reverse trials convert 14-21% vs freemium's 2.6%
- Loss aversion is powerful
- In developing markets, long free periods → demand saturation → never upgrade
- Analytics ARE the product differentiation — let users experience them first, then gate

### 3. ANNUAL BILLING: 17% Discount is Correct

15-20% is the sweet spot used by 50%+ of SaaS companies. Framing: "Paga 10 meses, llevate 12" (10 months, get 12) > "17% off".

### 4. FOUNDER PROGRAM: Refine the Lock-in

| Guardrail | Recommendation |
|-----------|---------------|
| Total founder slots | 20 max |
| Founder obligations | Testimonial within 60 days, 1 referral within 90 days, permission as case study |
| Price lock scope | Base plan only — add-ons at 50% off year 1, then full price |
| Upgrade path | Founders upgrade tiers but lose founder pricing on new tier |
| Churn protection | If founder cancels, lose founder pricing permanently |
| Tracking | Tag founder accounts; track referrals generated, testimonials, feature usage |

### 5. UNIT ECONOMICS TARGET MODEL

| Metric | 20 founders | 100 customers | 300 customers |
|--------|-------------|---------------|---------------|
| MRR | $360 | $3,360 | $12,000 |
| ARPU | $18 | $34 | $40 |
| Blended CAC | ~$0 | <$50 | <$100 |
| LTV:CAC | Infinite (organic) | >10:1 | >6:1 |
| Gross Margin | ~78% | ~92% | ~95% |
| Monthly Churn | <5% | <4% | <3% |
| NRR | 100% | 105% | 110% |

### 6. REVENUE COMPOSITION TARGET (12 months)

| Revenue Source | % of MRR | Driver |
|----------------|----------|--------|
| Base subscriptions | 65% | Core 3 tiers |
| Add-on modules | 25% | Cross-sell after 30 days |
| Annual plan premium (cash flow) | 10% | Discount incentive |
| Referral-driven new customers | 20% of new MRR | Referral program |

### 7. KEY PRICING RISKS

| Risk | Mitigation |
|------|------------|
| Too many founders at deep discounts | Hard cap at 20, track ROI per founder |
| Free tier attracts non-paying support consumers | Automate support, limit free tier aggressively |
| Competitors drop prices | Differentiate on value, not price |
| Currency devaluation in emerging market | USD-denominated pricing, local at central bank rate on payment day only |
| Add-on modules not adopted | Bundle in 30-day trials, show value in onboarding |
| Annual churn >50% (SMB reality) | Invest in onboarding, health scores, proactive support |

## Activation Triggers

Activate this advisor when the conversation involves:

- **Pricing changes:** plan prices, adding/removing tiers, restructuring feature gates
- **New feature monetization:** base plan vs add-on decision
- **Referral program:** modifying incentives, tracking, or structure
- **Revenue modeling:** projecting MRR, ARR, ARPU, unit economics
- **Competitor response:** competitor changes pricing or launches new plan
- **Discount requests:** customer asks for special deal or designing promo offers
- **Annual planning:** budget forecasting, infrastructure cost planning, hiring thresholds
- **Payment strategy:** payment processor changes, regional payment methods, currency handling
- **Churn analysis:** monthly/annual churn exceeds targets and pricing may be a factor
- **Expansion to new markets:** pricing localization for new countries
